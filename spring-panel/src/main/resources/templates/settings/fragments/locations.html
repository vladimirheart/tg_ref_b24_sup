Структура локаций
В одной вкладке редактируйте дерево бизнес → тип → город → локации, в другой управляйте live-синхронизацией из iikoServer API.
Источники iikoServer API

Эти адреса используются только для live-синхронизации департаментов в структуру локаций. Они не связаны с AI Ops и кредитами iiko biz. Если поле секрета оставить пустым, текущий сохранённый секрет не изменится.
