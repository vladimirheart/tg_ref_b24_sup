    Профили прокси и VPN

    Создайте именованные профили маршрутизации, чтобы потом выбирать их для проекта, подсистемы ботов и отдельных интеграций.

    Профиль Тип Маршрут Статус Действия
    Профили нужны, чтобы не копировать одинаковые прокси/VPN вручную для каждого маршрута.
    Для VLESS создайте несколько профилей (host, port, token), затем выберите их цепочкой в маршруте проекта/ботов. Первый профиль в списке — основной, остальные используются как резерв.

    Сетевые маршруты интеграций

    Задайте отдельные прокси/VPN для всего проекта и отдельно для подсистемы ботов. Можно использовать как ручные настройки, так и готовые профили.

    Весь проект
    Базовый маршрут для панели и интеграций. Если ниже для ботов выбран режим «Наследовать проект», будет использован именно этот блок.
    Профили можно выбирать обычными кликами. Повторный клик снимает выбор.
    Первый профиль — основной, дальше резервные. При проблеме соединения система переключится на следующий доступный профиль.
    Цепочка пока не выбрана.
    Если маршрут не прошёл проверку доступности, он исключается на это время перед новой попыткой.
    Сначала выберите режим. Для отдельного прокси заполните host/port, для VPN — название, endpoint и путь к конфигу.
    Подсистема ботов
    Отдельный маршрут только для Java/VK-процессов ботов. Удобно, если панель должна работать напрямую, а боты — через выделенный прокси или VPN.
    Профили можно выбирать обычными кликами. Повторный клик снимает выбор.
    Можно выбрать отдельную цепочку профилей только для процессов ботов.
    Цепочка пока не выбрана.
    Недоступный маршрут временно исключается и бот-процессы переключаются на следующий из списка.
    Если выбрать «Наследовать проект», боты будут использовать маршрут из левого блока без дублирования настроек.
    Прокси применяются к запросам панели и автоматически передаются отдельным процессам ботов. VPN сохраняется как конфигурация маршрута для окружения и конкретных ботов.

    Настройка VK Callback API
    1. Создайте ключ доступа сообщества с правами сообщений: «Работа с API» → «Ключи доступа».

    3. Вставьте код подтверждения и при необходимости секретный ключ, чтобы включить проверку запросов.
    4. Активируйте события сообщений и перед запуском сервиса выполните python vk_webhook_support.py.

    Куда бот пишет служебные уведомления и откуда брать адресатов для отправок.

    Можно оставить пустым — добавьте бота в нужную группу, и мы определим ID автоматически.
    Используется для отправки запланированных сообщений в канал.
    Очередь обращений

    Определяет, какая команда сопровождает новые обращения именно у этого бота и нужно ли сразу назначать ответственного.

    Можно выбрать несколько операторов. Для множественного выбора используйте `Ctrl` / `Cmd`.
    Если переключатель выключен, очередь всё равно получит обращение, но ответственный останется неназначенным до ручного действия оператора.
    Оповещения в панели

    Нужно только для режимов с отделом. Если оставить пустым, будет использоваться режим «Всем операторам».
    Список логинов через запятую, пробел или новую строку.

    Платформенные настройки

    Отдельные настройки только для VK/MAX, чтобы не шумели в общих сценариях.

    Учётные данные и синхронизация

    Просмотр текущего токена, его безопасная замена и обновление карточки бота.

    Текущий токен бота
    —
    Введите новый токен только если действительно хотите заменить текущие учётные данные канала.
    Принудительно обновляет имя и username через Telegram API. После смены токена можно сразу синхронизировать карточку бота.
    Сетевой маршрут

    Индивидуальная прокси/VPN-конфигурация этого бота поверх общей подсистемы.

    Профили можно выбирать обычными кликами. Повторный клик снимает выбор.
    Профиль можно переиспользовать для нескольких ботов; порядок выбора определяет failover-цепочку.
    Цепочка пока не выбрана.
    Если выбранный маршрут не доступен, бот перейдёт к следующему и вернётся к этому после истечения интервала.
    Если оставить «Наследовать настройки ботов», конкретный бот возьмёт маршрут из блока «Подсистема ботов».
    Настройки применяются только к выбранному боту и имеют приоритет над общими параметрами подсистемы.
    VK: настройки вебхука
    Найдите числовой идентификатор в настройках сообщества.
    Как подключить Callback API
    1. В разделе «Работа с API» → «Callback API» задайте адрес вида https://ваш-домен/webhooks/vk/<group_id>.
    2. Вставьте код подтверждения и при необходимости секретный ключ, чтобы проверять исходящие запросы.
    3. Включите события сообщений и запустите Java-бот через панель или команду Spring Boot.
