Допуск к модулю

Чтение разрешает участие в выбранных задачах и проектах. Состав каждого объекта настраивается отдельно. Системный администратор имеет полный доступ.

Журнал изменений доступа

    Доступ и участники

      Журнал изменений доступа

        Новый участник должен иметь допуск к модулю. Участие в проекте не открывает его задачи автоматически.

        При передаче прежний владелец остаётся редактором. Для старого объекта без владельца администратор может назначить нового.
