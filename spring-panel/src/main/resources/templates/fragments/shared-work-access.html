Общие права раздела

При доступе к странице «Задачи» сотрудник видит выбранные для него задачи и проекты без дополнительного допуска. Здесь можно явно запретить чтение или разрешить создание. Эти настройки не открывают чужие объекты. Системный администратор имеет полный доступ.

Журнал изменений доступа

    Доступ и участники

      Добавить участника

      Найдите сотрудника, выберите права и нажмите «Добавить / изменить». Изменение сохраняется сразу.

      В списке — активные сотрудники с доступом к странице «Задачи», без явного запрета чтения раздела. Добавление открывает только выбранный объект.

      Дополнительно

      Для передачи владения выберите сотрудника в форме добавления выше. Прежний владелец останется редактором.
