# Задача [01-178]

## Краткое описание

Исправить импорт фото из NetBox, который сейчас падает на image-attachments с `.jfif`, `application/octet-stream` и именами без расширения.

## Цель

Сделать sync паспортов объектов устойчивым: одно нестандартное фото из NetBox не должно ломать весь импорт.

## Контекст

- В логе панели sync падает в `ObjectPassportPhotoStorageService.store(...)` с ошибкой о допустимых форматах изображений.
- Проверка NetBox показала, что часть image-attachments приходит как:
  - `.jfif`;
  - `application/octet-stream`;
  - URL без расширения файла, хотя содержимое по сигнатуре является JPEG.
- Текущая логика storage опирается только на extension и content-type, чего для таких файлов недостаточно.

## Что сделать

- Добавить в `ObjectPassportPhotoStorageService` нормализацию `.jfif -> .jpg`.
- На входе `store(InputStream, ...)` уметь определять расширение по сигнатуре файла для JPEG/PNG/GIF/BMP/WebP.
- В `NetBoxObjectPassportSyncService` не валить весь sync на единичном неподдерживаемом изображении: логировать skip и продолжать импорт остальных фото.

## Критерии готовности

- Фото NetBox без расширения, с `.jfif` и с `application/octet-stream` успешно импортируются, если по сигнатуре это поддерживаемое изображение.
- Если попадается реально неподдерживаемый файл, sync продолжает работу, а в логах есть warning с привязкой к attachment/site.
- Сборка проходит.
