# Задача [01-187]

## Короткое описание

Убрать ложный Maven `BUILD FAILURE` при штатной остановке Windows runtime, не маскируя реальные аварийные завершения приложения.

## Наблюдение

При остановке panel пользователь видит от `spring-boot-maven-plugin:run` `Process terminated with exit code: 1` и итоговый `BUILD FAILURE`, хотя остановка инициирована оператором. Текущий `run-windows.bat` после `spring-boot:run` лишь принимает ненулевой ERRORLEVEL, выводит информационное сообщение и запускает cleanup порта; сам Maven успевает напечатать failure раньше launcher cleanup.

## Ограничение

Не фильтровать и не скрывать `BUILD FAILURE` текстом/redirect, потому что это может спрятать настоящее падение приложения.

## Направление решения

Отдельно пересмотреть lifecycle Windows launcher: запускать уже собранный application process под явным process ownership/stop contract либо иным способом отличать operator stop от crash до формирования итогового статуса launcher.

## Критерии готовности

- штатная остановка выглядит как успешный controlled shutdown;
- реальный crash остаётся ненулевым и видимым;
- cleanup не убивает чужие процессы;
- Ctrl+C/stop не запускает panel повторно;
- сценарий проверен на Windows runtime.
