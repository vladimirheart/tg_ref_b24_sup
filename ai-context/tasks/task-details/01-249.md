# Задача [01-249] Уплотнить UI источников iikoServer API сворачиваемыми карточками

## Короткое описание

Вкладка live-синхронизации локаций постоянно показывала полные формы всех
`iikoServer API` источников. При нескольких источниках это занимало значительную
часть модального окна и создавало визуальный шум.

## Цель

Показывать сохранённые источники компактно и раскрывать поля редактирования только
по запросу оператора, не меняя backend/save contract.

## Что сделать

- Сохранённые источники по умолчанию показывать свёрнутыми карточками.
- В свёрнутой карточке показывать название чейна, URL, логин, enabled-статус и
  состояние секрета.
- Полную форму раскрывать по клику на карточку.
- Новый источник автоматически раскрывать для заполнения.
- Сохранять раскрытое состояние при локальном rerender, в том числе после смены
  `enabled` и сохранения формы.
- При повторном открытии settings-модалки начинать с компактного состояния.
- Сохранить существующие save/sync/remove contracts.

## Критерии готовности

- Два и более сохранённых источника не занимают страницу полными формами.
- Раскрытие/сворачивание не меняет данные источника.
- Новый источник виден сразу как раскрытая форма.
- Смена `enabled` не захлопывает редактируемую карточку.
- Targeted source-contract test проходит.
