# Задача [01-193]

## Короткое описание

Ужесточить security bootstrap и secret contract spring-panel для production contour.

## Цель

Убрать опасные production-дефолты из security bootstrap панели, чтобы внешний production-контур не мог стартовать с `admin/admin`, дефолтным internal bot token и предсказуемым remember-me key.

## Контекст

- Сейчас `spring-panel` автоматически поднимает bootstrap-администратора и допускает опасные значения по умолчанию в security-конфигурации.
- Для SQLite/dev-режима нужно сохранить удобный локальный старт, но production contour должен работать по fail-fast контракту.
- Внутренний bot API уже защищен токеном, но дефолтное значение токена недопустимо для внешней БД и shared runtime.

## Что сделать

- Ввести production guard для ключевых security-secret значений.
- Перевести bootstrap администратора на явные credentials для external DB режима и сохранить dev-friendly fallback только для SQLite.
- Обновить конфигурацию и документацию по новым security env vars.
- Добавить тесты на fail-fast и bootstrap contract.

## Критерии готовности

- `spring-panel` не стартует во внешнем production-like режиме с дефолтным internal bot token.
- `spring-panel` не стартует во внешнем production-like режиме с дефолтным remember-me key.
- При отсутствии admin-пользователя внешний runtime требует явные bootstrap credentials, а SQLite-режим сохраняет локальный fallback.
