# Задача [01-330]

## Короткое описание

Устранить подтверждённые дубли, разделить обязанности крупных модулей и общих
стилей, вывести старые артефакты восстановления из рабочего дерева с сохранением копии.

## Scope

- bot-settings.js: удалить перекрытые объявления, выделить самостоятельные
  части редактора с неизменными данными и поведением.
- auth-management.js: самостоятельные компоненты профиля/фото, ролей, оргструктуры;
  сохранять authoritative state, права и существующие точки входа.
- RmsLicenseMonitoringService: отделить чистый разбор лицензий и транспортные
  проверки от очередей/оркестрации, сохраняя роли, DTO/API и lifecycle.
- Общие SCSS-компоненты: единый владелец правил, устранение конкурирующих
  объявлений с проверкой вычисленных стилей и поведения.
- Исторические recovery-артефакты: точный перечень, проверенный внешний архив,
  ignore/manifest/restore instructions. Не удалять рабочие данные и fixtures.

## Ограничения

Рабочий экземпляр развёрнут на другой машине. Без соединений с ним и его БД,
миграций, deployment, staging/commit/push, переписывания истории Git. Не менять
бизнес-поведение, security policy, legacy credentials или IDs. Не разделять
модули только ради числа строк. Исторические snapshot bytes не переписывать.

## Проверки

До применения в основной checkout: targeted Java/Node/browser regressions,
сравнение поведения/стилей с baseline, Sass/JAR, syntax/diff/content/exact-file guards.
Состояние применения будет подтверждено отдельным ignored audit JSON.
