# Задача [01-250] Исправить раскрытие, вложенность и theme-aware бейджи дерева локаций

## Короткое описание

Во вкладке «Структура» бизнес корректно стартует свёрнутым, но после его раскрытия
все дочерние уровни оказываются открыты одновременно. Кроме того, leaf-локации
визуально уходят левее строки города, потому что у города есть колонка toggle, а у
локации её нет. Служебные meta-бейджи используют Bootstrap `text-bg-light` и
становятся белыми в тёмных/кастомных темах.

## Цель

Сделать дерево последовательным: business → type → city → location раскрывается
по одному уровню, каждая локация визуально остаётся внутри своего города, а
служебные pills используют theme tokens Iguana.

## Что сделать

- При первом открытии структуры seed'ить collapsed-state для business, type и city.
- Раскрытие business показывает типы, но не раскрывает автоматически города и локации.
- Раскрытие type показывает города, но города остаются свёрнутыми до отдельного клика.
- Сдвинуть leaf-локации вправо на недостающую ширину toggle+gap; на mobile убрать этот compensation offset.
- Заменить `text-bg-light` у metadata pills на theme-aware класс.
- Исправить сохранённый-secret badge во вкладке iikoServer тем же theme-aware подходом.
- Не менять tree payload, save contract и backend.

## Критерии готовности

- После раскрытия бизнеса виден только следующий уровень дерева.
- Локации начинаются правее строки города и читаются как его дочерние элементы.
- Metadata pills и badge «Секрет сохранён» не становятся белыми в тёмной теме.
- Светлая/тёмная/кастомная темы используют существующие CSS variables.
- Targeted source-contract test проходит.
