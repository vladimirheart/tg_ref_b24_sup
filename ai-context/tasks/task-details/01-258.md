# Задача [01-258] Уплотнить каталог паспортов, добавить титульные фото и reversible soft-delete

## Контекст

Пользователь продолжает шлифовку страницы общего списка паспортов объектов `/object-passports`. Старые тестовые паспорта ID 1–9 нельзя физически удалять: выбран обратимый статус `Удалён`.

## Что сделать

- Уплотнить desktop-шапку списка до одной строки: заголовок, поиск, icon-only фильтры и создание паспорта с `title`/`aria-label`.
- В колонке «Департамент» показать миниатюру титульного фото `category == title`, иначе нейтральный placeholder.
- Показывать floating preview спустя 500 мс hover/focus; при переходе курсора с миниатюры на preview сохранять его открытым, закрывать при уходе с увеличенного preview, а также при blur/scroll/resize.
- Усилить контраст badge «Обращения» в light/dark; финальный размер цифр допускается подобрать визуально, сохранив жирное начертание и контраст.
- При zoom-out список паспортов должен занимать всю доступную ширину; при горизонтальном overflow таблицы сверху должна быть доступна синхронизированная горизонтальная прокрутка.
- Добавить backend-поля `title_photo_url` и `deleted`; распознавать `Удалён`/`Удален`/`deleted`.
- Добавить статус `Удалён` в defaults.
- По умолчанию исключать deleted из visibility scope и счётчиков; вернуть их переключателем «Показывать удалённые» либо явным фильтром статуса `Удалён`.
- Визуально отличать deleted row/status.
- Не выполнять data mutation ID 1–9 до production rollout UI.

## Критерии готовности

- Source-contract test фиксирует compact actions, thumbnail/preview delay и hover-handoff, soft-delete visibility/counters, читаемый badge, full-width list и верхний synchronized horizontal scroll.
- `git diff --check`, inline JS syntax check и targeted Maven test проходят.
- Generated `static/css/app.css` напрямую не редактируется.
- Задача остаётся 🟣 до production rollout и ручной визуальной проверки.
