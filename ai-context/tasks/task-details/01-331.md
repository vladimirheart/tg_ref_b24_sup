## Результат

Проверены все семь пунктов исходного документа. Baseline 197/190/7 подтверждён;
пять падений относятся к устаревшим source/asset assertions, два — к неполным
DOM/window fixtures. Assertions доступа, exact-ID и payload не удалялись.
Исправлены также реальные дефекты: гонка истории A/B и HTML ошибки, ложный
успех malformed provider HTTP 200, неверная классификация MAX not.ready,
неоднозначные автоматические повторы через другой provider endpoint/host,
двойное чтение response body в настройках и потеря ошибок POST upload.

Добавлены общий browser PanelErrors, Java MessagingErrorParser, безопасная
диагностика входящих файлов и Nginx JSON errors. Подробности/границы:
[аудит](../../../docs/architecture/node-regression-audit-331.md),
[контракт](../../rules/15-readable-messaging-errors.md).
