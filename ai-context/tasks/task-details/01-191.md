# Задача [01-191]

## Короткое описание

Обновить текущую документацию Iguana, включая UI-правила и актуальную архитектуру проекта.

## Цель

Собрать в актуальном наборе документов реальную архитектуру `spring-panel` и `java-bot`, текущие UI-конвенции, правила хранения состояния интерфейса, карту модулей, конфигурации, данных и потоков интеграции, чтобы документация отражала состояние репозитория на 25 августа 2026 года.

## Контекст

- В репозитории уже есть большой набор исторических документов по архитектуре, storage и PostgreSQL-first переходу, но нужен свежий входной документ, который можно использовать как основную актуальную точку входа.
- UI проекта строится на server-rendered Thymeleaf-шаблонах, Bootstrap, наборе page-specific JS runtime-модулей и общей подсистеме UI preferences (`ui-preferences.js`, `theme.js`, `ui-config.js`).
- Архитектурные границы проекта разделены между `spring-panel/`, `java-bot/`, `config/shared/`, runtime storage и `ai-context/rules/backend/`.
- Изменения должны быть оформлены по правилам `ai-context/tasks` и `ai-context/changelog`.

## Что сделать

- Проверить текущий `README.md`, `docs/` и проектные AI-правила.
- Снять фактическую архитектуру из кода `spring-panel` и `java-bot`, а не только из исторических документов.
- Обновить входную документацию и добавить подробный актуальный документ с архитектурой, UI-правилами, потоками данных и правилами развития.
- Зафиксировать изменения отдельной changelog-записью.

## Критерии готовности

- В репозитории есть актуальный подробный документ, который описывает архитектуру проекта и UI-правила на текущем состоянии кода.
- `README.md` направляет читателя к этому документу и не противоречит ему.
- Изменения оформлены с отдельной changelog-записью.

## Обязательные дополнительные условия

- По завершении задачи показать alert через `./ai-context/baseline/scripts/show-completion-alert.sh`, если пользователь отдельно не отменил это требование.
- В финальном ответе подготовить `Резюме для коммита` по формату из `ai-context/baseline/guides/tasks.md`.
- После любых file changes создать отдельный changelog-файл в `ai-context/changelog` и включить в него пользовательский промпт, который привёл к изменению.
