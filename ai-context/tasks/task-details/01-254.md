# Задача [01-254] Уплотнить шапку диалога, composer и добавить SLA-пульсацию метрик

## Короткое описание

В модальном окне диалога шапка перегружена текстовыми кнопками. Регулятор размера
текста постоянно занимает место, composer имеет лишний заголовок и крупную кнопку
отправки, а блок «Метрики» визуально не сообщает оператору о текущем SLA-состоянии.

## Цель

Сделать окно диалога визуально спокойнее и компактнее без потери доступности
действий и без изменения backend-контрактов.

## Что сделать

- Перевести header actions «Взять себе», «Участники», «Передать», «Задача»,
  «Спам», «Категории», «Закрыть», «Переоткрыть» в компактные icon-only controls.
- Для каждой иконки сохранить aria-label/title и показать описание по hover/focus.
- Перенести размер текста в иконку в том же action-row; range показывать только
  после клика и закрывать по outside click/Escape.
- Убрать видимую подпись «Ответ клиенту», сохранив aria-label у textarea.
- Уменьшить вертикальный разрыв между историей и composer.
- Кнопку «Отправить» сделать icon-only и фиксированного размера; изменение высоты
  textarea не должно растягивать кнопку.
- Блок «Метрики» должен пульсировать по реальному состоянию
  `DialogsSlaRuntime.computeSlaState(activeDialogRow)`:
  safe — зелёный, risk — предупреждающий, overdue — красный, closed — без пульсации.
- Для prefers-reduced-motion заменить пульсацию статичным SLA-акцентом.
- Обновить cache-busters dialogs runtime/app.css.
- Удалить три случайно попавших в main operator-файла 01-253.
- В media preview убрать визуальную modal-header, оставив только floating close.
- Zoom/download controls перевести в компактные icon-only controls и убрать
  отдельный footer, чтобы media stage получал больше полезной площади.
- Generated CSS напрямую не редактировать.

## Критерии готовности

- Шапка диалога занимает заметно меньше места и состоит из компактного icon action-row.
- Tooltip/aria-label объясняют каждое действие.
- Range размера текста появляется только по клику на иконку.
- Composer не содержит видимую надпись «Ответ клиенту».
- Send icon остаётся 2.5rem независимо от resize textarea.
- Metrics pulse соответствует существующему SLA runtime state.
- Media preview не имеет шапки/заголовка и отдельного footer; остаётся floating close.
- Zoom/download — компактные иконки поверх media stage.
- Targeted source-contract test, node --check и isolated SCSS compilation проходят.
