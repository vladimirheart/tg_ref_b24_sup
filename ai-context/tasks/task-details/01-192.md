# Задача [01-192]

## Короткое описание

Зафиксировать production readiness checklist и runbook запуска Iguana.

## Цель

Собрать единый практический документ, по которому можно безопасно провести запуск Iguana в production-контур: подготовить инфраструктуру, проверить конфигурацию, выполнить cutover, откат и первичную пост-релизную верификацию.

## Контекст

- По состоянию репозитория на 25 августа 2026 года production contour проекта опирается на `spring-panel`, `java-bot`, `PostgreSQL`, `Redis`, `RabbitMQ` и S3-совместимое хранилище.
- В репозитории уже есть архитектурные и readiness-документы, но отсутствует один короткий и операционно-полезный runbook запуска.
- Этот артефакт нужен как для локальной команды, так и для последующих релизов и аудитов перед запуском.

## Что сделать

- Собрать финальный production checklist по инфраструктуре, секретам, хранилищам, очередям, health-check и откату.
- Описать пошаговый runbook: preflight, deploy, smoke, rollback, первая неделя наблюдения.
- Сослаться на существующие документы по PostgreSQL-first и production contour, не дублируя их полностью.

## Критерии готовности

- В репозитории есть отдельный production runbook, пригодный для реального запуска.
- Checklist покрывает конфигурацию, безопасность, миграцию, интеграции и наблюдаемость.

## Обязательные дополнительные условия

- По завершении задачи показать alert через `./ai-context/baseline/scripts/show-completion-alert.sh`, если пользователь отдельно не отменил это требование.
- В финальном ответе подготовить `Резюме для коммита` по формату из `ai-context/baseline/guides/tasks.md`.
- После любых file changes создать отдельный changelog-файл в `ai-context/changelog` и включить в него пользовательский промпт, который привел к изменению.
