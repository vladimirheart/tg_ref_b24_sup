# Задача [01-217] Мигрировать legacy media и avatars в MinIO/S3, убрать runtime-зависимость от local attachments и подготовить безопасный финальный purge

Статус: 🟡 В работе

## Краткое описание

Перевести исторические вложения и аватары из legacy local filesystem в production object storage и завершить переход так, чтобы локальные каталоги больше не являлись runtime dependency. Физический cleanup выполняется отдельно, только через доказанный manifest-driven quarantine и с сохранённым rollback window.

## Цель

- canonical runtime storage — MinIO/S3;
- attachment metadata соответствует реальной доступности canonical objects;
- local fallback после успешного cutover выключен;
- известные невосстановимые исторические вложения явно зафиксированы и не маскируются placeholder-объектами;
- оставшиеся локальные файлы инвентаризируются и сопоставляются без destructive операций;
- quarantine и физическое удаление отделены друг от друга и требуют отдельных решений оператора.
