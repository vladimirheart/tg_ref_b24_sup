## Изменения

Восемь `APP_MULTIBUSINESS_*` inputs в env/Compose/application mapping, foundation
nested; defaults false, canonical override precedence сохранены. Flat alias
binder collision исключён. Source сам ничего не активирует.
Bot core классифицирует HTTP/auth/service/writer/JSON failures и пишет только
route без query, QNR-код, status. Telegram/MAX/VK показывают эти коды вместо
бесконечного /start. Legacy409 handshake/stale selection, auth/scope/hash/writer
checks и запрет fallback сохранены. MAX явные /start и /cancel могут заменить/
удалить legacy draft до runtime precheck; обычный ответ по-прежнему требует scope.
Runbook описывает прежний R319/R322 набор flags, выпуск image, пересоздание трёх
сервисов с прежними Compose arguments, rollback point и functional acceptance.
