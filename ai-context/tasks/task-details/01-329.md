## Короткое описание

Единое оформление редакторов прав сотрудника и роли.

## Цель и scope

Общий компонент разделов прав с поиском, сворачиванием, счётчиками и адаптивными
строками. Различия между правами роли, индивидуальными исключениями и итогом
остаются явными. Стили этого компонента и карточки роли собрать в одном SCSS partial,
убрав прежние конкурирующие определения. Без переписывания CSS всей панели.

## Ограничения

- Не менять серверную модель прав, API, wildcard, запреты, наследование и capabilities.
- Сохранять защищённые/readonly поля, legacy page grants и точные account IDs.
- Поиск/сворачивание не исключают скрытые строки из сохранения.
- Производство находится на другой машине. Без DB/deploy/staging/commit/push.

## План и критерии готовности

1. Общий компонент и оба редактора; убрать дублирование CSS.
2. Проверить реальные шаблоны и assets в Edge: светлая/тёмная тема, телефон,
   низкое окно, поиск, клавиатура, allow/deny/inherit, wildcard, readonly, сохранение.
3. Выполнить необходимые regression tests, Sass/build, diff/content/exact-file guards.
4. Применить проверенные файлы в основной checkout только после GREEN.

## Проверки и состояние

- Общий `PermissionEditor` используется сотрудником и ролью: поиск с восстановлением
  раскрытых разделов, счётчики, адаптивные строки, нативная клавиатура/labels.
- Индивидуальные права явно показывают наследование, исключение и итог. Поиск и
  сворачивание не теряют изменений. При ошибке PUT черновик остаётся, повторные
  клики во время сохранения и устаревшие ответы при переключении пользователя защищены.
- Общие стили в `scss/settings/_permissions.scss`, один entrypoint
  `permission-editor.scss` / `permission-editor.css` для `/settings` и `/users`.
  Прежние role styles убраны из legacy/calm/infrastructure. Заголовок роли имеет
  собственный класс, чтобы generic collapse CSS не добавлял вторую стрелку.
- Backend, API, модель прав и миграции не менялись. Сохранены wildcard, legacy page
  grants, числовые account IDs как строки, readonly и защищённая системная роль.
