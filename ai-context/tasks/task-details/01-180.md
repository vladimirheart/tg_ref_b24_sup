# Задача [01-180]

## Краткое описание

Добавить в настройки синхронизации NetBox выбор конкретных `sites`, которые должны импортироваться в Iguana, с предварительной загрузкой списка из NetBox и отображением поля `Status`.

## Цель

Дать пользователю явный контроль над составом импортируемых объектов без ручного редактирования конфигурации и без необходимости синхронизировать весь NetBox целиком.

## Контекст

- Сейчас sync всегда запрашивает все `sites` из NetBox и далее импортирует их целиком.
- Пользователь хочет сначала получить список `sites`, затем вручную отметить нужные к загрузке.
- Для принятия решения в списке нужно показывать `Status` каждого объекта.

## Что сделать

- Расширить `netbox_sync`-settings хранением выбранных `site_id`.
- Добавить backend-эндпоинт, который по текущим параметрам подключения возвращает список NetBox `sites` c `id`, именем и `Status`.
- Добавить UI в блок NetBox sync: загрузка списка, выбор/снятие выбора, индикация количества выбранных sites.
- Ограничить сам sync выбранными `site_id`, сохранив обратную совместимость: если список выбора пуст, импортировать все sites.

## Критерии готовности

- Пользователь может загрузить список `sites` из NetBox до запуска sync.
- В списке отображаются как минимум `name`, `id` и `Status`.
- Выбранные `site_id` сохраняются в настройках и используются последующими sync.
- При пустом выборе sync продолжает импортировать все `sites`.
- Сборка проходит.
