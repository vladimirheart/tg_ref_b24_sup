# Задача 01-305

## Короткое описание

Открывать фото и каскадно выбирать модели в каталоге оборудования.

## Цель

Дать оператору возможность просматривать загруженные фотографии прямо из
карточек каталога и выбирать оборудование в логической последовательности
«тип → производитель → модель».

## Контекст

`/api/settings/it-equipment` уже содержит точные тройки полей мастер-каталога.
Они заполняются синхронизацией NetBox из `device_role`,
`device_type.manufacturer` и `device_type.model`. Текущая форма использует
три независимых набора значений, поэтому допускает несовместимые комбинации.
Фото в карточке каталога сейчас не является интерактивным, хотя просмотрщик
фото уже существует для формы редактирования модели.

## Что сделать

- Открывать обложку и галерею фото из карточки каталога без перехода к редактированию модели.
- Построить каскад значений типа, производителя и модели из загруженных
  строк каталога, включая импортированные NetBox-тройки.
- Сделать фильтры каталога зависимыми и добавить фильтр модели.
- Добавить регрессионные проверки и обновить cache-busting assets.

## Критерии готовности

- Клик по фото на карточке открывает существующий просмотрщик на обложке модели.
- Производитель доступен только для выбранного типа, модель — только для
  выбранных типа и производителя.
- Фильтрация не показывает модели, не принадлежащие выбранной ветви.
- Нет миграций, backfill или сетевых обращений к NetBox из браузера.

  `./ai-context/baseline/scripts/show-completion-alert.sh`, если пользователь отдельно
  не отменил это требование.
- В финальном ответе подготовить `Резюме для коммита` по формату из
