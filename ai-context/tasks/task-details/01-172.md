# Задача [01-172]

## Краткое описание

Добавить в настройки NetBox и Notion явное удаление сохранённых токенов, чтобы shared settings можно было безопасно очищать перед синхронизацией проекта в GitHub.

## Цель

Дать пользователю штатный UI-механизм, который реально удаляет сохранённые секреты из `settings.json` без ручного редактирования файла и без двусмысленности "оставить поле пустым = сохранить старый токен".

## Контекст

- Для NetBox токен сейчас хранится в `netbox_sync.api_token`, а пустое поле в UI означает "не менять текущий токен".
- Для Notion knowledge integration действует такая же логика: пустое поле `token` сохраняет старое значение.
- Пользователь отдельно попросил сохранить возможность безопасной синхронизации проекта в GitHub, поэтому нужно именно явное удаление токена через интерфейс.

## Что сделать

- Добавить в настройки NetBox явный флаг/действие удаления сохранённого токена.
- Обновить backend `NetBoxSyncSettingsService`, чтобы он умел очищать `api_token` при сохранении.
- Добавить в настройки интеграции Notion явный флаг/действие удаления сохранённого token.
- Обновить `KnowledgeBaseNotionService` и форму настроек Notion так, чтобы очистка токена происходила при сохранении без ручного редактирования JSON.

## Критерии готовности

- Пользователь может удалить сохранённый токен NetBox из UI, после чего он реально исчезает из `settings.json`.
- Пользователь может удалить сохранённый токен Notion из UI, после чего он реально исчезает из `settings.json`.
- Пустое поле без явного флага удаления по-прежнему означает "оставить текущий токен".
- Сборка затронутого модуля проходит.
