## Результат

- Feedback event обновляет диалог через realtime без создания bell-уведомлений.
  Исторические оценки отфильтрованы общим SQL-предикатом до pagination, из unread
  count и read/read-all. В рабочей БД до rollout найдено 29 таких записей;
  физическое удаление уведомлений и оценок не выполнялось.
- Общая нормализация текста в NotificationService заменяет ссылки на внутренний
  ID каноническим номером на записи и чтении, включая AI/SLA, действия оператора,
  категории и участников. Регистр legacy ID сохраняется; словоформы русского
  заголовка сопоставляются без учёта регистра отдельно от идентификатора.
  Маршрут URL и ownership tuple остаются точными. При отсутствии номера нет UUID fallback.
- Telegram/VK/MAX: summary получает результат awaitClientTicketNumber, совпадающий
  с подтверждением клиенту. Новые ответы клиента техническому каналу также
  используют номер. Общее форматирование добавляет источник, платформу, имя
  канала и разделитель. BUSINESS raw-summary prohibition и sender admission не менялись.
- Внешние уведомления панели имеют заголовок источника; RMS и SSL подписаны
  отдельно. Клиентские сообщения закрытия/опроса не превращались в технические.
- NotificationDto дополнен source/sourceLabel без DB migration. Sidebar использует
  фиксированные значки/цвета Bootstrap и подписи разделов, с fallback по URL для
  старого payload. Неизвестный источник — Система. Произвольный source/HTML не
  попадает в классы/разметку. Обновлена версия sidebar.js в общем navbar.
