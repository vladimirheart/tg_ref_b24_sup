# Задача [01-229] Удалить SQLite compatibility perimeter из production-исходников, UI и reference-документации

## Короткое описание

После подтверждённого переноса данных убрать SQLite compatibility perimeter из production-исходников и привести UI/документацию к PostgreSQL-only модели.

## Цель

Не оставить в проекте вводящие в заблуждение production-пути, например сообщение UI о том, что бот работает на собственной SQLite БД, а SQLite оставить только в тестовых fixtures и в архивной migration utility при необходимости.

## Зависимость

Выполнять после ручной приёмки `01-228`: пока исходные SQLite-файлы и import evidence нужны для rollback, удалять compatibility-код и документацию преждевременно.

## Что сделать

- Провести аудит datasource, Flyway migration, bootstrap и bot JDBC compatibility кода.
- Удалить или изолировать неиспользуемые production SQLite paths.
- Исправить устаревший UI и reference-документацию.
- Сохранить отдельный архивный import tool, если он нужен для исторических инсталляций.

## Связанные правила

- `ai-context/baseline/guides/tasks.md`

## Прогресс 2026-09-17 — structural slice 1

- Dependency gate снят: `01-228` принята пользователем и закрыта в `🟢`.
- Для `spring-panel` explicit `APP_DB_MODE=sqlite` больше не является selectable runtime mode: parser отклоняет его до datasource/bootstrap wiring.
- Удалён retired `EnvDefaultsInitializer` и оба startup registration path (`PanelApplication` и `META-INF/spring.factories`).
- Backend rule и high-signal reference docs переведены с local/dev SQLite compatibility формулировок на archive/test-only perimeter.
- Explicit archive import/verification tooling, legacy source evidence и bot `worker` technical store этим slice не удаляются.
- Задача остаётся `🟡`: следующим structural slice нужно удалить/схлопнуть уже unreachable panel SQLite datasource/bootstrap classes и проверить оставшийся UI/reference surface.

### Safety

- Production runtime/deployment не перезапускаются.
- DB migration/backfill не выполняются.
- Legacy SQLite import не запускается.
- NetBox/external systems не изменяются.
