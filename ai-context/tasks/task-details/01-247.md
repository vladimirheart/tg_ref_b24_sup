# Задача [01-247] Отображать пересланные сообщения MAX в истории активного диалога

## Короткое описание

MAX-бот игнорировал пересланное пользователем сообщение, если верхний `body` отсутствовал.

## Цель

Сохранять текст и медиа пересылки в активную заявку и показывать оператору автора исходного сообщения.

## Контекст

- MAX API возвращает оригинальное сообщение в `message.link`; внешний `body` может быть `null`.
- Внешний `sender` остаётся клиентом, который переслал сообщение в бот; исходный автор должен попадать в `forwarded_from`.
- Telegram уже передаёт пересылку в историю; поведение MAX должно быть эквивалентным.

## Что сделать

- Извлечь text/attachments из forward-link при пустом внешнем body.
- Передать имя автора через existing `forwardedFrom` integration contract.
- Добавить unit regression test с реальным shape `message_created` и `link.type=forward`.

## Критерии готовности

- Пересланный из MAX текст появляется в истории активного диалога.
- UI показывает «Переслано от <автор>» без создания второго обращения.
- Обычный MAX message flow и webhook dedup не регрессируют.
