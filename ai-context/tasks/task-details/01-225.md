# Задача [01-225] Довести persisted credential rotation до Bash parity и remaining apply contour

## Краткое описание

После закрытия Windows-first apply-path для `postgresql`, `rabbitmq`, `redis` и `minio`
остаётся добить эксплуатационный контур: Linux/Bash parity, controlled apply для
`grafana` и сценарии bulk/rehearsal rotation.

## Почему это важно

- production cutover не должен зависеть только от PowerShell/Windows;
- observability admin credential тоже должен иметь повторяемый controlled rotation path;
- rehearsal и bulk-переключения уменьшают риск ручных ошибок в реальном cutover.

## Что нужно сделать

1. Реализовать Bash-версию apply workflow с тем же contract, что у PowerShell-скрипта.
2. Добавить controlled apply-path для `grafana` с verify и rollback guidance.
3. Продумать и автоматизировать bulk/rehearsal flow для серии rotation steps.
4. Обновить runbook и smoke-проверки под Linux-first execution path.

## Критерии готовности

- Linux/Bash apply workflow покрывает тот же supported contour.
- `grafana` имеет repeatable controlled rotation path.
- Есть rehearsal guidance для multi-component rotation.

## Связанные задачи

- `01-224` — coordinated Redis/MinIO migration и restart choreography
- `01-223` — component-specific apply workflow для persisted credentials
