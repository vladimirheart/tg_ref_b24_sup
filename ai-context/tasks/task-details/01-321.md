## Результат

- Вместо шести постоянно открытых секций — пять вкладок: бизнесы, доступы,
  локации, каналы, вопросник. По умолчанию открыт только каталог. Вкладки
  поддерживают клавиатуру; счётчики показывают объём записей раздела.
- Формы создания/назначения и справочные пояснения открываются по требованию.
  Общие доступы выделены в отдельную свёрнутую группу со счётчиком. Роли
  подписаны по-русски. Действия каталога находятся в меню с троеточием.
- В каталоге, доступах, локациях и каналах есть поиск. Доступы и локации
  показываются для выбранного бизнеса; повторяющаяся колонка бизнеса убрана.
  Архивные владельцы и записи доступны для просмотра, создание/назначение для
  архивного бизнеса отключено. Пустые списки и результаты поиска объяснены.
- Длинные таблицы имеют собственную прокрутку и закреплённую шапку, широкие
  таблицы прокручиваются внутри страницы. Меню каталога использует fixed Popper
  и не обрезается таблицей. Выбор сотрудников использует общий EmployeePicker
  с исходными scoped native options; раскрытое меню находится в потоке формы.
- Смена вкладки/закрытие формы сохраняет ввод. Отказы API не сбрасывают ввод
  и не вызывают автоматический повтор записи. Существующие подтверждения
  отзыва/архивирования, CSRF, URL/method/payload, backend guards и CAS вопросника
  сохранены. Новых grants, глобального fallback, SQL и миграций нет.
- Стили страницы вынесены в отдельный SCSS/CSS; cache versions CSS/JS обновлены.
