# Задача [01-256] Уплотнить карточку клиента и улучшить список/историю обращений

## Цель

Сделать карточку клиента компактнее и быстрее для оператора, перенеся редкие действия в модалки и приблизив preview истории к основному окну диалога.

## Что сделать

- Свести page header карточки клиента в одну строку на desktop.
- Перенести среднюю оценку в «Статистика».
- Перенести телефоны в «Основную информацию»: основной номер + количество остальных, управление в modal.
- Перенести историю юзернейма в кнопку `i` рядом с «Юзернейм».
- Переименовать «Заявки клиента» в «Обращения клиента».
- Показывать requestNumber, а при отсутствии — ticketId.
- Добавить локацию в header обращения.
- Сохранить ticketId как внутренний API identifier.
- Улучшить preview истории: dialog-like rows/bubbles, sender/time/reply/forwarded/edited/deleted metadata, media preview.
- Добавить кнопку «Открыть полный диалог».
- Добавить requestNumber в ClientProfileTicket из messages.group_msg_id.
- Обновить app.css cache-buster.
- Generated CSS напрямую не редактировать.

## Критерии готовности

- Desktop header занимает одну строку.
- Телефоны и username history больше не занимают отдельные карточки.
- Раздел называется «Обращения клиента».
- Номер обращения и локация видны в accordion header.
- Preview истории визуально близок к основному диалогу.
- Из preview можно открыть полноценный диалог.
- Existing client edit/blacklist/phone API actions не регрессируют.
- Source-contract test, template JS node --check, git diff --check и isolated SCSS compile проходят.
