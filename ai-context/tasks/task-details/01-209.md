# Задача [01-209]

## Короткое описание

Починить bootstrap secret contract локального PostgreSQL-контура для `spring-panel/run-windows.bat`.

## Цель

Сделать так, чтобы локальный first-run path `PostgreSQL + RabbitMQ`, который создаётся bootstrap-скриптами Iguana, поднимал `spring-panel` без ручного дописывания production-required секретов в `.env`, но при этом не ослаблял fail-fast guard для реального external / production-like контура.

## Контекст

- На `25 августа 2026 года` `PanelSecurityRuntimeGuard` уже валидирует `APP_INTERNAL_BOT_API_TOKEN` и `APP_SECURITY_REMEMBER_ME_KEY` в external database режиме.
- Старые bootstrap-версии создавали локальный `.env` для PostgreSQL без этих ключей, поэтому `run-windows.bat` доходил до запуска Spring/Flyway и падал на `panelSecurityRuntimeGuard`.
- Локальный launcher уже добавляет совместимые session-only defaults для `APP_COORDINATION_MODE=direct` и object-storage readiness, то есть contour задуман как безопасный dev/local bootstrap, а не как production deployment.
- Нельзя просто ослабить `PanelSecurityRuntimeGuard`: для production-like контура fail-fast должен сохраниться.

## Что сделать

- Обновить `scripts/bootstrap-first-run.ps1`, чтобы новый локальный `.env` для PostgreSQL сразу получал безопасные случайные значения для:
  - `APP_INTERNAL_BOT_API_TOKEN`;
  - `APP_SECURITY_REMEMBER_ME_KEY`.
- Обновить `scripts/bootstrap-first-run.sh` симметрично, чтобы Linux bootstrap не расходился по контракту с Windows.
- Добавить в Windows launcher auto-heal для уже существующих bootstrap-generated `.env`, если:
  - contour локальный `postgresql` bootstrap;
  - секреты отсутствуют или оставлены на bootstrap/default placeholder.
- Не подменять явные пользовательские env overrides и не вмешиваться в production-like contour с `Redis/S3`-требованиями.
- Обновить связанные env/docs-комментарии там, где это помогает понять новый контракт.

## Критерии готовности

- Новый bootstrap-generated `.env` для локального PostgreSQL-контура содержит безопасные значения `APP_INTERNAL_BOT_API_TOKEN` и `APP_SECURITY_REMEMBER_ME_KEY`.
- `spring-panel/run-windows.bat` умеет долечить старый локальный `.env`, созданный до этого фикса.
- `PanelSecurityRuntimeGuard` остаётся неизменным по своей security-семантике и продолжает валить настоящий production-like contour на дефолтных секретах.
- Изменения подтверждены хотя бы targeted validation/smoke-проверкой.

## Обязательные дополнительные условия

- После любых file changes создать отдельный changelog-файл в `ai-context/changelog` и включить в него пользовательский промпт, который привёл к изменению.
