# Задача [01-194]

## Короткое описание

Внедрить базовый observability stack и SLI/SLO для production contour.

## Цель

Добавить стандартный производственный слой наблюдаемости для Iguana: системные метрики, application metrics, health endpoints, latency/error dashboards и алерты, чтобы readiness-проверки не оставались единственным инструментом контроля.

## Контекст

- В проекте уже есть прикладные monitoring-сценарии и readiness checks, но нет типового production observability stack уровня `Actuator/Micrometer/Prometheus`.
- Без базовой телеметрии запуск внешнего контура остается операционно рискованным.

## Что сделать

- Добавить базовые application metrics и health endpoints.
- Зафиксировать минимальный набор SLI/SLO и порогов алертинга.
- Подготовить документацию по подключению Prometheus/Grafana и базовым production dashboards.

## Критерии готовности

- У `spring-panel` есть стандартные health/metrics surfaces для production.
- В репозитории описан минимальный observability baseline и его алерты.
