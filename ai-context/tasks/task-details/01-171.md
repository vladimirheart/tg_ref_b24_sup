# Задача [01-171]

## Краткое описание

Интегрировать NetBox в паспорта объектов Iguana с одноразовой полной перезаписью тестовых данных и регулярным sync.

## Цель

Сделать управляемую интеграцию, которая подтягивает `dcim/sites` из NetBox в паспорта объектов Iguana, импортирует оборудование, фото и сетевые параметры, один раз полностью заменяет текущие тестовые паспорта, а дальше работает как безопасный upsert без дублей.

## Контекст

- Пользователь подтвердил каноническое правило: `1 site NetBox = 1 паспорт объекта + оборудование внутри него`.
- В качестве первичного источника используется NetBox `3.0.6`, объектный пример согласован на `site/296`, для circuit-данных дополнительно подтверждён `site/117`.
- Пользователь отдельно подтвердил, что текущие паспорта объектов в Iguana являются тестовыми и их можно полностью переписать один раз, чтобы дальше уйти от дублей.
- Для `business` согласован источник `tenant.name`, для `schedule` — `custom_fields.WorkTime`, для `city` — парсинг из адреса с fallback на `region`.
- `site.comments` импортируются целиком по явному решению пользователя, несмотря на риск наличия служебных данных.
- Если у сайта несколько каналов связи, главным считается самый быстрый active-circuit, остальные должны сохраняться в агрегированный техблок.
- Все `site images` должны импортироваться в паспорт; фото с названием `ЗО` нужно делать титульным только если в Iguana ещё нет титульного фото.
- Помимо самих паспортов нужно подтягивать значения для блока «Подключения IT-блока», чтобы справочники типов/вендоров/моделей/статусов оборудования не расходились с импортом.

## Что сделать

- Добавить NetBox-настройки в shared settings и UI страницы настроек: URL, токен, включение автосинхронизации, интервал, ручной запуск и статус последней sync.
- Реализовать backend-клиент NetBox и sync-сервис с загрузкой sites, devices, circuits и image attachments через REST API.
- Сделать одноразовый режим полного overwrite паспортов объектов на первом sync и переключение на дальнейший upsert по стабильному `netbox_site_id`.
- Собрать и сохранить мэппинг NetBox -> Iguana для полей паспорта, расписания, сетевых параметров, оборудования и фото.
- Обновлять связанные справочники оборудования/IT-блока из NetBox-данных без ручного ввода ключевых значений пользователем.
- Добавить API статуса/запуска sync и встроить его в settings runtime по образцу существующей iiko sync.

## Критерии готовности

- В настройках панели есть отдельный контур NetBox sync с ручным запуском, расписанием и понятным статусом выполнения.
- Первый sync полностью заменяет существующие тестовые паспорта объектов, а повторные sync не создают дублей и обновляют те же записи по `site`.
- В паспорте объекта после sync корректно отображаются карточка объекта, оборудование, сетевые параметры, расписание и фото из NetBox.
- Значения, нужные для редактора оборудования и блока «Подключения IT-блока», подтягиваются из импортированных данных и не требуют ручного дописывания для базового сценария.
- Токен NetBox не попадает в репозиторий, changelog и клиентский payload в открытом виде.
- Есть локальная проверка сборки или компиляции затронутых модулей.
