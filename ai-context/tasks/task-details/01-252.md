# Задача [01-252] Унифицировать disclosure/accordion-паттерн по всему UI

## Короткое описание

Карточки источников iikoServer получили удачный disclosure-паттерн: спокойная theme-aware поверхность, понятное collapsed/expanded состояние и плавное раскрытие. В остальных разделах используются разрозненные Bootstrap accordion/collapse и native details.

## Цель

Сделать единый project-wide disclosure language для контентных раскрывающихся блоков, не превращая navigation/toolbars/action toggles и popup media-menu в карточки.

## Что сделать

- Ввести canonical disclosure SCSS последним слоем app bundle.
- Выровнять все Bootstrap accordion по языку iikoServer cards.
- Выровнять card-header collapse по тем же surface/border/radius/hover/expanded правилам.
- Пометить runtime native details классом ui-disclosure-native, кроме media popup menu.
- Добавить плавное раскрытие native details с prefers-reduced-motion fallback.
- Добавить last-cascade settings compatibility для IT/channels.
- Не редактировать generated app.css/settings.css/style.css напрямую.

## Критерии готовности

- Disclosure/accordion surfaces единообразны в light/dark/custom themes.
- Expanded header использует surface-selected, hover surface-interactive.
- Native details раскрываются плавно.
- Chat media info popup не меняет UX.
- Settings IT/channels не перебивают canonical style legacy rules.
- Targeted source-contract test проходит, generated CSS не меняется.
