# Задача [01-226] Добавить Grafana apply-path и multi-component rehearsal для persisted credential rotation

## Краткое описание

После PowerShell/Bash parity оставался критичный observability-хвост: `grafana`
ещё диагностировалась, но не имела controlled apply-path, а для multi-component
rotation не было зафиксированного rehearsal порядка.

## Почему это важно

- observability admin credential тоже должен ротироваться через повторяемый безопасный workflow;
- ручной cutover без зафиксированного порядка шагов всё ещё слишком рискован;
- после закрытия `postgresql` / `rabbitmq` / `redis` / `minio` именно Grafana оставалась последним незакрытым supported component.

## Что сделано

1. `scripts/docker-production-credential-migration-apply.ps1` расширен на `grafana`.
2. `scripts/docker-production-credential-migration-apply.sh` расширен на `grafana`.
3. Для Grafana в обоих entrypoint реализованы:
   - live auth preflight по `http://<bind-host>:<port>/api/user`;
   - fallback resolution текущего пароля;
   - live reset через `grafana cli admin reset-admin-password`;
   - обновление `IGUANA_GRAFANA_ADMIN_PASSWORD` в `.env`;
   - recreate сервиса `grafana`;
   - post-restart auth verification;
   - best-effort rollback live password, `.env` и recreate.
4. Runbook `docs/runbooks/persisted-credential-rotation-apply.md` обновлён под новый supported contour и теперь содержит рекомендуемый ручной rehearsal порядок для multi-component rotation.
5. Обновлён source-contract
   `spring-panel/src/test/java/com/example/panel/runtime/PersistedCredentialRotationApplySourceContractTest.java`.

## Проверка

На живом compose project `tg_ref_b24_sup` успешно прошли dry-run:

- `powershell -ExecutionPolicy Bypass -File .\scripts\docker-production-credential-migration-apply.ps1 -Component grafana`;
- `C:\Program Files\Git\bin\bash.exe -lc 'cd /c/Users/SinicinVV/git_h/tg_ref_b24_sup && ./scripts/docker-production-credential-migration-apply.sh --component grafana'`.

Оба dry-run подтвердили:

- live Grafana authentication проходит;
- planned update касается `IGUANA_GRAFANA_ADMIN_PASSWORD`;
- recreate планируется только для `grafana`.

## Что осталось

- bulk rotation нескольких компонентов за один прогон;
- automation-friendly rehearsal flow;
- optional pre-apply backup snapshot кроме `.env` checkpoint.
