# Задача [01-226] Добавить Grafana apply-path и multi-component rehearsal для persisted credential rotation

## Краткое описание

После PowerShell/Bash parity у apply workflow остаётся эксплуатационный хвост:
controlled rotation для `grafana` и сценарии multi-component rehearsal/bulk rotation.

## Почему это важно

- observability admin credential тоже должен иметь повторяемый безопасный rotation path;
- multi-step cutover без rehearsal/bulk guidance всё ещё слишком ручной;
- после закрытия Bash parity это самый рискованный оставшийся участок.

## Что нужно сделать

1. Реализовать controlled apply-path для `grafana` с verify и rollback guidance.
2. Добавить runbook для rehearsal нескольких rotation steps в одном окне работ.
3. Продумать bulk orchestration для серии component rotation с проверками между шагами.
4. Обновить source-contract тесты и документацию под новый охват.

## Критерии готовности

- `grafana` ротируется через repeatable controlled apply-path.
- Есть rehearsal/bulk guidance для multi-component rotation.
- Runbook покрывает post-change verification и rollback expectations.

- `01-225` — Bash parity для apply workflow
- `01-224` — coordinated Redis/MinIO migration и restart choreography
