# Задача [01-281]

## Короткое описание

Распространить утверждённую визуальную систему Neutral Ops на весь пользовательский веб-интерфейс Iguana, включая основные рабочие разделы, административные страницы, общие компоненты и публичные веб-экраны.

## Цель

Добиться единого спокойного и плотного операционного интерфейса, аналогичного одобренному автономному превью `Iguana-Neutral-Ops-Preview.html`, для всех веб-поверхностей проекта. Сохранить бизнес-логику, маршруты, DOM-контракты, безопасность, API, данные и рабочие сценарии.

## Принципы визуального контракта

- Neutral Ops — общая базовая система нейтральных поверхностей, границ, размеров, типографики и плотности; семантические цвета (danger/warning/success/SLA) **сохраняют различимость**.
- Светлая/тёмная/системная яркость, контраст, focus-visible, клавиатура, touch-targets, screenreader/ARIA, длинные названия, локализация и responsive — обязательны.
- Рабочая плотность — без исчезновения функций: не прятать действия/ошибки/контекст только ради вида. Не нарушать sticky, resize, scroll, z-index, сложные таблицы и формы.
- Существующие палитры, пользовательские настройки темы и API preferences сохраняются до отдельного согласованного этапа миграции темы; самовольно удалять варианты/сбрасывать предпочтения нельзя.
- Уважать текущие архитектурные ветки `01-277` (PostgreSQL-only) и `01-278` (бизнес-скоуп): визуальная работа не обходит их permission/UI contracts и не меняет runtime.
- Не менять production Java, JS, SQL, БД, внешний контент, bootstrap/vendor sources и бизнес-логику в визуальных source-only шагах без отдельного разрешения.
