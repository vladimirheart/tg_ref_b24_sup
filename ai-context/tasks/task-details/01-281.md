# Задача [01-281]

## Короткое описание

Внедрить Neutral Ops-вёрстку для диалогов и операционной аналитики.

## Цель

Перенести утверждённое владельцем визуальное направление из автономного
превью в рабочие страницы Iguana, не меняя их поведение, API и данные.

## Контекст

Владелец оценил автономное превью `Iguana-Neutral-Ops-Preview.html` как
существенно более приятное. Нужны те же принципы на рабочих страницах
`/dialogs` и dashboard: спокойные поверхности, ясная иерархия, меньше
градиентов и декоративных эффектов, компактные KPI и операционная плотность.

## Что сделать

- Добавить scoped Neutral Ops SCSS-слой для диалогов и dashboard.
- Включить слой через явный `data-ui-visual` только в двух целевых шаблонах.
- Сохранить существующие идентификаторы, runtime-классы, контроллеры и данные
  графиков без изменений.
- Пересобрать CSS штатным Maven-пайплайном и проверить шаблоны компиляцией.

## Критерии готовности

- Диалоги и dashboard используют единый сдержанный visual language в светлой и
  тёмной темах.
- Изменения не затрагивают Java, JavaScript, API, БД и runtime-поведение.
- SCSS resource generation, компиляция и `git diff --check` проходят.
