# Задача [01-231] Исправить битую UTF-8 кодировку fallback-ответа Telegram-бота для стикеров

## Короткое описание

Вернуть читаемый клиентский ответ Telegram-бота, когда стикер приходит до обнаружения активного диалога.

## Цель

Клиент не должен получать replacement-символы вместо русского текста, а fallback должен объяснять, как создать новое обращение.

## Контекст

- `SupportBot.notifyNoActiveDialog()` вызывается для вложений, включая sticker, когда не найден активный тикет.
- В commit `8a702a189e` строка была заменена на повреждённые символы `U+FFFD`.
- Правильный исходный текст доступен в родительской версии этого commit.

## Что сделать

- Вынести текст fallback-ответа в package-visible метод.
- Вернуть корректную UTF-8 строку: `Активного диалога нет. Напишите сообщение, и я создам новое обращение.`
- Добавить unit-тест на точный читаемый текст.
- Собрать и протестировать модуль `bot-telegram`.

## Критерии готовности

- При отсутствии активного диалога клиент получает читаемый русский fallback.
- Тест защищает строку от повторной порчи кодировки.
- Стикер продолжает сохраняться и обрабатываться текущим маршрутом.

## Обязательные дополнительные условия

- По завершении показать алерт через `./ai-context/baseline/scripts/show-completion-alert.sh`.
- В финальном ответе подготовить `Резюме для коммита`.
- После file changes создать отдельный changelog в `ai-context/changelog` с пользовательским промптом.
