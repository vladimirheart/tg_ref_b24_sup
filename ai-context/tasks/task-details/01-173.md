# Задача [01-173]

## Краткое описание

Сделать ручной запуск NetBox sync из UI использующим текущие значения формы, даже если пользователь ещё не нажал общее сохранение настроек.

## Цель

Убрать ложную ошибку `Укажите base URL NetBox`, когда URL уже введён в модалке `Подключения IT-блока`, но ещё не был сохранён в `settings.json`.

## Контекст

- Сейчас `POST /api/settings/netbox-sync/run` стартует sync только по уже сохранённым shared settings.
- Пользователь ввёл `https://netbox.sushivesla.su`, но получил ошибку в ручном запуске, потому что кнопка run не передала текущее состояние формы на backend.
- Для UX это должно работать без обязательного предварительного `Сохранить настройки`, как минимум в пределах самого блока NetBox.

## Что сделать

- Обновить endpoint ручного запуска NetBox sync так, чтобы он умел принять текущий payload `netbox_sync`, применить его в shared settings и только потом запускать sync.
- Обновить frontend runtime NetBox, чтобы он отправлял текущее состояние формы при нажатии `Запустить sync сейчас`.
- После успешного run обновлять локальное состояние runtime как сохранённое, чтобы UI не оставался в "грязном" состоянии.

## Критерии готовности

- При вводе URL/token в NetBox-блоке ручной run работает сразу, без обязательного общего сохранения страницы.
- Ошибка `Укажите base URL NetBox` не возникает, если URL уже введён в форме и успешно принят backend.
- Сборка затронутого модуля проходит.
