# Задача [01-251] Сделать свёрнутые карточки источников iikoServer API theme-aware

## Короткое описание

После перевода источников iikoServer API в сворачиваемые карточки disclosure-логика
работает корректно, но заголовки свёрнутых карточек продолжают использовать Bootstrap
`bg-body` / `text-body` и `text-bg-*`. В тёмной/кастомной теме это даёт белые
поверхности и выбивается из Iguana theme tokens.

## Цель

Убрать Bootstrap-светлые presentation classes из disclosure-карточек iikoServer и
оформлять их только через semantic runtime classes + source-SCSS Settings.

## Что сделать

- Удалить `bg-body`, `text-body`, `text-muted` и `text-bg-*` из визуального
  оформления disclosure-карточек источников.
- Добавить semantic-классы для card/header/toggle/meta/actions/body/status badges.
- Описать presentation только в `settings/_calm.scss` через
  `--surface-*`, `--color-*` и `--state-*`.
- Сделать empty-state списка источников theme-aware.
- Не редактировать generated `static/css/settings.css` и `app.css` напрямую.
- Не менять backend, shared-config, save/sync contract и disclosure-state.

## Критерии готовности

- В тёмной теме свёрнутые карточки не имеют белого фона.
- Светлая и кастомные темы наследуют те же Iguana tokens.
- Enabled/disabled/warning badges не зависят от Bootstrap `text-bg-*`.
- Expanded body сохраняет нормальный контраст и разделитель.
- Targeted source-contract test проходит.
- Targeted test не изменяет generated `app.css/settings.css`.

## Связанные файлы

- `spring-panel/src/main/resources/static/js/settings-locations-iiko-runtime.js`
- `spring-panel/src/main/resources/scss/settings/_calm.scss`
- `spring-panel/src/test/java/com/example/panel/runtime/SettingsLocationsIikoSourceThemeSurfaceContractTest.java`
