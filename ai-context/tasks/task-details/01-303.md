## Короткое описание

Открывать фото оборудования в паспорте объекта и показывать сведения бабблом без раскрытия карточки.

с блока внутри карточки и увеличивала её высоту.

## Изменения

- Фото оборудования открывается кнопкой в общем просмотрщике паспорта. Галерея
  содержит фотографии выбранной модели из каталога, стартует с её обложки и
  поддерживает стрелки, клавиатуру, Escape, фон и возврат фокуса к исходному фото.
- Фото объекта и фото оборудования используют отдельные наборы снимков.
- Кнопка i открывает один немодальный баббл, вынесенный из карточки в body, чтобы
  overflow и hover transform карточки не обрезали сведения.
- Сведения позиционируются рядом с кнопкой с учётом свободного места; высота
  ограничена 420 px и доступным местом, длинный текст прокручивается внутри.
- Закрытие по повторному клику, крестику, Escape, клику/фокусу снаружи, поиску и
  смене вкладки. Профиль комплектации продолжает подгружаться в открытый баббл.
- Изображения доступны с клавиатуры; просмотрщик удерживает фокус внутри и
  возвращает его при закрытии. Обновлены версии трёх runtime и CSS паспорта.
