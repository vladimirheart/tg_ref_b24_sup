# 2026-08-25 10:03 — observability baseline and actuator

## Что сделал
- Подключил Spring Boot Actuator и Prometheus registry для `spring-panel`.
- Добавил базовую конфигурацию observability: `health`, `info`, `metrics`, `prometheus`, health-groups для `liveness` и `readiness`, а также базовые метки Micrometer.
- Реализовал `ProductionReadinessHealthIndicator`, который публикует итоговый статус прод-готовности в `/actuator/health/readiness`.
- Реализовал кэш наблюдений и кастомные метрики для готовности компонентов, очередей RabbitMQ и outbox-доставки инцидентов.
- Обновил security-правила, чтобы инфраструктурные health/probe endpoints были доступны для оркестратора и мониторинга.
- Добавил подробную документацию по observability baseline, SLI/SLO, алертам и Prometheus scrape-конфигурации.

## Зачем
- Чтобы у проекта появился минимально достаточный слой мониторинга для прод-запуска: health probes, метрики приложения, понятные сигналы по очередям и доставке инцидентов.
- Чтобы операционный контур support-системы можно было подключить к Prometheus/Grafana и быстро диагностировать деградации по зависимостям и фоновой доставке.
