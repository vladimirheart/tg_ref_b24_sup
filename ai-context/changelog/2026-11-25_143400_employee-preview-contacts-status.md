# 01-315 — Общее превью сотрудника с контактами и статусами

Промт пользователя:

> кстаааати... например из задач я могу кликнуть по пользователю и откроется его превью. нужно чтобы из превью пропал логин, но появились контактные данные и его статус как активности так и блокировки. и такая возможность должна быть из любого места проекта где есть пользователь совершивший действие

## Изменения

- Общий EmployeeProfiles preview показывает ФИО, фото, отдел, email, телефоны,
  Online/Offline, последнее время активности и «Активен/Заблокирован».
  Логин не отображается даже при пустом ФИО. Контакты безопасно экранируются;
  mailto/tel доступны по нажатию. Прежний размер фото в settings не меняется.
- Общий read-only API расширен минимальной проекцией контактов и статусов,
  serverTime и отдельным параметром userId. ID — decimal string, поддерживается
  BIGINT > 2^53; неоднозначные username по-прежнему не выбирают случайную УЗ.
  Секреты, роли/права и дата рождения не проецируются; прежняя проверка действующего
  аккаунта SharedSystemAccessService.REQUIRE сохранена.
- Подключены авторы действий в задачах/канбане, shared-work audit, диалогах и
  аватарах операторов, истории работы/назначений/участников, blacklist и решениях
  заявок, заметках, документах паспортов, AI/incidents/transport audit, пользователях
  и оргструктуре. При наличии ID поиск выполняется по нему. Свободный текст и
  внешние авторы пересылок не подменяются identity сотрудника. Не найденные
  legacy/system авторы остаются текстом; имя не используется как доказательство ID.
- Свежие данные при открытии, обновление открытого preview раз в минуту,
  серверное время для порога 30 минут. Защищены retry, смена пользователя,
  поздние ответы и быстрое повторное открытие. Escape сохраняет нижние окна и
  черновики. Обновлены cache versions изменённых JS/CSS.
