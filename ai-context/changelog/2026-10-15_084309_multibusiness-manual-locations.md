# 01-278 R89: ручные локации для независимых бизнесов

- Время: 2026-10-15 08:43:09 MSK.
- Промт пользователя: «продолжи».
- Области: `BusinessAdministrationService`,
  `BusinessAdministrationApiController`, страница и JS каталога бизнесов,
  PostgreSQL/WebMvc-тесты, `ai-context/tasks/task-details/01-278.md`.

В каталоге бизнесов добавлены локации: администратор может создать локацию
в активном бизнесе, архивировать и восстановить её без удаления ID. Локации
с одинаковым именем в разных бизнесах независимы; внутри одного бизнеса
повтор точного нормализованного ключа отклоняется. Внешние интеграции,
каналы и старые обращения автоматически не связываются.

API остаётся за глобальными `PAGE_SETTINGS` и `ROLE_ADMIN`, а также
выключенным по умолчанию foundation flag. В изолированной PostgreSQL 16
схеме и WebMvc прошли 7/7 целевых тестов, `node --check` прошёл. Рабочая
БД, backfill, flags, deployment, staging/commit/push не затронуты.
Задача остаётся 🟡.
