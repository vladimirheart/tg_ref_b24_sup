# 01-304 — Индикатор создания RMS

Время: 2026-11-23 09:20:48 Europe/Moscow.

## Промт пользователя

```text
на странице http://127.0.0.1:8080/analytics/rms-control при добавлении новой записи нужно отобраение что действие выполняется, как это сделано при перезапуске или запуске ботов. иначе непонятно состояние
```

## Изменения

- В форме добавления RMS появилась доступная строка статуса и spinner с текстом
  «Добавляем RMS…» на кнопке отправки; форме выставляется `aria-busy`.
- Пока POST-запрос активен, повторная отправка игнорируется. После успеха или
  ошибки кнопка, статус и возможность отправки возвращаются к исходному виду.
- Версия подключаемого `rms-monitoring.js` изменена, поэтому браузер загрузит
  обновлённый клиентский сценарий без старого кэша.
- Добавлен Node-регрессионный тест создания RMS для состояния ожидания, ошибки
  и последующей повторной попытки. Web MVC-проверка синхронизирована с новой
  версией asset.
