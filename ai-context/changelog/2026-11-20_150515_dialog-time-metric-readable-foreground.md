# 01-302 — Контраст времени обращения

Промт пользователя:

> нихера непонятно что написано. использую тёмный режим и северную палитру

Приложен скриншот диалога: стрелка указывает на светлую плашку «Время обращения»,
значение на которой сливается с фоном.

## Изменения

- Исправлена причина: плашка брала пользовательский светлый фон, а цвет текста
  наследовала из тёмной темы. Для north/dark измерено 1.0378:1 до исправления.
- Текст плашки теперь явно чёрный/белый, выбирается больший контраст по luminance
  заданного фона. Сохраняются корректные пользовательские hex-цвета, пороги,
  длительность и отсутствие плашки при неизвестном времени.
- Поддерживаются #rgb/#rrggbb; некорректный цвет заменяется стандартным фоном зоны.
- Обновлена cache version dialogs-details-runtime.js: 20261120-time-contrast-r1.
  Палитры, SCSS/CSS, backend, права, настройки и рабочие данные не менялись.
- Добавлен browser regression по реальным computed styles в пяти палитрах и двух
  режимах, включая пользовательские цвета и значения good/warning/danger.
