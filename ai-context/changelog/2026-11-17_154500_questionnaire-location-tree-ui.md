# Локации единого вопросника и читаемый редактор шаблона

## Промт пользователя

> почему-то не подтягивается инфо из структуры локаций. да и в целом ui у шаблона тяжело читается - ни разделителей нормальных ни компановки

## Выполнено

- Для единого вопросника дерево локаций теперь фильтруется по бизнесам
  канала и получает канонические имена, используемые в ответе на вопрос
  `business`. Различие регистра в исходной интеграции (например,
  `БлинБери` и `Блинбери`) больше не делает следующие вопросы пустыми.
- В runtime не попадают ветки локаций не привязанных к каналу бизнесов.
- Редактор шаблона вопросов разбит на визуальные секции; карточки вопросов,
  дополнительные настройки и варианты ответов получили явные границы,
  отступы и контрастную подложку.

## Проверка

- `BotRuntimeConfigServiceTest` подтверждает преобразование дерева
  `БлинБери` в канонический ключ `Блинбери`.
- Выполнены `mvnw.cmd -q -Dtest=BotRuntimeConfigServiceTest test` и
  `node --check src/main/resources/static/js/bot-settings.js`.
- Собран образ `iguana-panel:local`; перезапущены `panel-web`, `ops-worker`
  и `bot-runner`. Readiness всех трёх сервисов — `UP`.
- Signed runtime API каналов `1` и `2` подтверждает шаблон
  `tpl_unified_businesses_v1` и ключи дерева `Блинбери`, `СушиВёсла`.
