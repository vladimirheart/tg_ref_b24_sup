# Резервная доставка ответа оператора в Telegram

- Время: 2026-11-18 15:15:40
- Затронутые области: отправка текстовых ответов оператора Telegram, сетевой маршрут провайдера, unit-тесты.

## Промт пользователя

> пытаюсь отправить ответ оператором, но получаю "Ошибка отправки сообщения в Telegram.". сообщения от клиента приходят.

## Изменения

- Зафиксирована причина из журнала доставок: Telegram API-зеркало ответило `502 Bad Gateway` на `sendMessage` канала `tst`, хотя приём входящих сообщений продолжал работать.
- Для текстового ответа оператора добавлен один ограниченный резервный запрос напрямую к официальному Telegram Bot API только при `502`, `503` или `504` от legacy-зеркала. Обычный маршрут и все остальные ошибки не меняются.
- Добавлен отдельный direct HTTP-клиент без маршрута канала и unit-тест, подтверждающий успешную доставку через резервный маршрут после ошибки зеркала.
