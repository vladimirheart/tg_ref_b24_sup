## Исправления и фактическая приёмка

1. Typed Docker inspect содержал ExposedPorts/Volumes {} markers как plain Object.
   Jackson падал до подключения fixture. Локальный inspection mapper допускает
   empty beans; verifyNetwork/verifyService/verifyRelay и cleanup guards сохранены.
   Добавлены6 регрессий для real typed response: service без host ports допускается,
   публичные/loopback service ports отвергаются; relay допускает только loopback.
   Эти6 cases сначала воспроизвели serializer error.
2. MockMvc HTTP bridge оставлял query '+' вместо пробела; exact padded/Unicode
   root не совпадал с SQL и давал409. Только fixture декодирует query параметры
   как servlet, сохраняя исходную raw query для HMAC. Добавлены9 регрессий exact
   root/large user ID/повторных encoded keys; до исправления все9 были RED.
3. Два duplicate-root drift cases теперь требуют точный
   AmqpRejectAndDontRequeueException/message из R291 principal boundary и отсутствие
   inbox: неоднозначный root отвергается до ingestion. Остальные drift cases
   по-прежнему требуют IllegalStateException и failed inbox. Проверки отсутствия
   history/metadata сохранены; для всех6 drift cases добавлена неизменность
   ticket_active.user_identity. Тип исключения не расширен до RuntimeException.
   Перед изменением actual PG/Rabbit выполнил42 cases:40 PASS,2 старых assertions RED.
4. Runner ожидает90 contracts:26 chain +8 linked wire +41 fixture network
   +6 repository adapters +9 query. Phase=R301; штатное имя r292-proof.json сохранено.
   Матрица57 integration cases и её isolation/error/cleanup guards прежние.
