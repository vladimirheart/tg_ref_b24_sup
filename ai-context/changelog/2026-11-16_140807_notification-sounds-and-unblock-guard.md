## Промпт пользователя

> а давай запилим звуки для
>
> - оповещений системы общего характера
> - для оповещений системы инцидентов
> - для нового сообщения в диалоге
> - для оценок диалога

>

## Выполнено

- Добавлен глобальный Web Audio runtime с пятью короткими различимыми
  синтезированными сигналами: системный, incident, новое сообщение, оценка и
  запрос разблокировки. Аудиофайлы и внешняя загрузка не используются.
- Sidebar публикует изменения счётчиков уведомлений и unblock-заявок; runtime
  не озвучивает историческое состояние, ждёт первого действия оператора для
  разблокировки браузерного аудио и подавляет общий звук для конкретных событий
  сообщения/оценки.
- Incident-уведомления распознаются по внутреннему URL `/incidents`; прочие
  непрофилированные уведомления используют системный сигнал.
- Исправлен blacklist lifecycle: panel runtime и legacy bot-core не создают
  заявку и не меняют blacklist для активного клиента; создание заявки блокирует
  строку blacklist до завершения операции.
- Решение оператором по заявке теперь выполняется в транзакции с `FOR UPDATE`.
- Telegram и VK явно сообщают активному клиенту, что он не заблокирован, вместо
  отправки `/unblock` в lifecycle заявки.
- Добавлены тесты на отклонение активного клиента и успешное создание заявки
  для заблокированного клиента.
