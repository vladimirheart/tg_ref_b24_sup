## Реализовано

- DialogTicketLifecycleService: resolve/reopen/categories и activity/feedback
  followups разрешены только для unique UNRESOLVED до strict:
  business_id IS NULL, is_general=FALSE. Namespace schema отсутствует либо
  marker NULL — отказ; exact raw ID не преобразуется.
- Все 13 прежних SQL сохраняют unique-root proof и повторяют namespace +
  sampled strict binding. Root SELECT/UPDATE используют непосредственный
  predicate текущей строки: UPDATE после root-lock wait повторно проверяет
  committed BUSINESS/GENERAL. Child statements проверяют UNRESOLVED owner
  в подзапросе; это не общий lock на всю цепочку.
- Quick actions проверяют допуск после lifecycle до success AI/provider/bell/
  SSE callbacks; категории — до и после void writer, spam — до глобального
  blockClient и после категорий. Начальный namespace/strict отказ не вызывает
  блокировку. Reopen assignment callback также повторяет namespace proof;
  собственный full-owner writer R160 не изменён.
- Raw audit quick_close/resolve/reopen/categories/mark_spam включён в защищённые
  mutation actions R160/R162: namespace/unique proof в INSERT, strict до/после
  lookup. Сохранены unrelated action/telemetry, historical raw audit lookup.
- Status quirks, actor/category normalization, counters/timestamps, feedback
  source/expiry и прежняя best-effort семантика UNRESOLVED сохранены.
  BUSINESS/GENERAL scoped services не изменены. Source minimum V80;
  новой SQL migration нет. Task summary/семь блоков/ближайшая очередь и S0
  актуализированы; общий статус 01-278 остаётся 🟡.

Это namespace-hardening, не transaction/generation-bound lifecycle.
UNRESOLVED ABA, partial followups и смена strict после binding не сериализованы.
Общая blacklist/recipient policy не закрыта: уже разрешённая блокировка не
откатывается, если namespace изменился позднее. Raw audit не объявляется
полностью business/generation-attributed, unrelated telemetry/read остаются
отдельным контрактом. Child concurrency и прочие legacy writers требуют аудита.

OPERATE/CAS и atomic audit/outbox; не открывать raw fallback для ROLE_ADMIN.
