# 01-300 — Оргструктура и карточка сотрудника

Промт пользователя:

> настройки -> пользователи панели -> орг.структура.
>
> 1. отображается криво не в виде дерева, хотя ветки есть
> 2. составы пустые
> 3. при открытии состава и попытке выбрать пользователя, список не помещается в окне, то есть окно нужно сделать по умолчанию больше
>
>
>
> плюс карточка сотрудника выглядит очень шумно и криворасположено

## Изменения

- Дерево получило отступы, линии связей и кнопки сворачивания; циклы и потерянные
  родители не скрывают записи. Parent ID и исходный shared-config не переписываются.
- Состав объединяет ручные members и сотрудников по department: полный путь либо
  однозначное старое имя. Источник показан явно. Сотрудник по отделу редактируется
  через свою карточку, ручные назначения — через общий EmployeePicker.
- Существующий native memberIds/FormData и scoped options сохранены. Недоступные
  выбранные IDs остаются видимыми и не теряются при сохранении других участников.
  Preview состава обновляется при выборе; применение и сохранение структуры разделены явно.
- Окно состава увеличено до 960 × 740 с ограничением viewport, исправлена структура
  scrollable form/modal-content, меню picker расположено в потоке с прокруткой.
  Сохранено пользовательское изменение размеров окна.
- Карточка сотрудника: компактное фото, сетка основных полей, контакты и закрытая
  по умолчанию безопасность; при создании безопасность раскрыта. Отдел показан
  полным путём. Все прежние поля, обработчики и workforce bridge сохранены.
- SCSS пересобран, cache versions settings.css/auth-management.js обновлены.
  Исправлен точный устаревший asset marker существующего workforce contract.

## Валидация и границы

проверенный cache с source/content guards; обновлённый test перекомпилирован,
полная компиляция Java не заявляется. Maven Sass/resources и JAR repackage GREEN.
8 браузерных сценариев от 320 до 1440 px в обеих темах, включая выбор, save/reload,
профиль, read-only и resize. Реальный MVC markup и production scripts/styles,
fixture API без рабочего сервера. Source audit и diff check GREEN.
