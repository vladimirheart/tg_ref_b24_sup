# 01-303 — фото оборудования и всплывающие сведения

## Запрос пользователя (дословно)

```text
уже немного лучше.
давай вернёмся к пасорту объекта. во вкладке оборудования, у оборудования есть фото, но открыть это фото я не могу. и при клике на тултип карточка раскравается, наверное лучше отображать бабблом?
```

## Выполнено

Фото оборудования открывается в просмотрщике с галереей выбранной модели,
начиная с обложки. Кнопка сведений показывает отдельный баббл рядом с кнопкой,
с внутренней прокруткой длинных описаний и закрытием по Escape, крестику,
повторному клику или снаружи. Размер карточки не меняется. Подгрузка профиля
комплектации, поиск, архив и отдельная галерея фото объекта сохранены.

## Проверки и границы

22 targeted Java tests, 8 browser viewport/theme scenarios и 6 дополнительных
взаимодействий GREEN. Северная палитра проверена в light/dark, 320–1440 px.
Исходное отсутствие открытия фото воспроизведено тем же browser harness.
SCSS/CSS, cache versions и JAR resources проверены; main Java не менялась,
использован проверенный cache после сравнения исходников, два test class
перекомпилированы. Рабочие БД/сервер не затрагивались. Staging/commit/push/deploy
не выполняются AI. Подробности и evidence — в task-details/01-303.md.
