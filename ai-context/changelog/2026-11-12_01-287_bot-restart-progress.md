# 01-287 — Перезапуск бота и индикаторы выполнения

Промты пользователя:

```text
в настройках бота нужно не только старт\стоп кнопку, но и перезапуск. плюс нужно отображение, что действие выполняется, хотя-бы крутящийся вид
```

В ходе работы: «продолжи».

Baseline / HEAD / локальный origin/main: `31ecce7f06d5f6ed0283c0762374fa8dd797b5de`.

Изменения:

- В списке каналов и редакторе добавлен «Перезапустить». Используется существующая команда start, которая останавливает прежний процесс и ждёт готовности нового; signed runner-путь, серверные права и API не менялись.
- Единое выполнение действий по каналу: spinner/текст на кнопке и в статусе, aria-busy/aria-live, блокировка дублей, независимость других каналов. Старые GET не перезаписывают результат команды и чужой открытый редактор; перерисовка списка восстанавливает progress.
- Ошибка HTTP/сети/подтверждения и клиентский timeout возвращают управление с сообщением об ошибке без автоматического повтора. Учитывается существующее право изменения каналов, включая отзыв прав. Обновлены версии четырёх JS assets.
- Добавлены Node-регрессии и браузерный fixture runner; lifecycle probe доказывает реальную смену PID и завершение старого процесса. Устаревшие fixtures приведены к действующему active/permission contract, assertions не ослаблены.

Валидация: 7 Node-тестов, 35 Java-тестов / 4 набора, 4 браузерных контекста light/dark × 390/1440 px — GREEN. Синтаксис JS и git diff --check — GREEN. Java-наборы запущены через Surefire после targeted javac изменённых test classes; production Java не менялась. Probe JAR не обращается к провайдерам и остановлен в finally.

Браузер использует реальные fragment/JS/permissions и локальный HTTP fixture: spinner на задержанном ответе, duplicate suppression, перерисовка, start/stop/restart, отказ/повтор, отзыв прав. Отчёт и 4 снимка под `spring-panel/target/bot-lifecycle-ui-qa`.

source_applied=true; staged=false; committed=false; pushed=false; deployment=false. Отдельный source sandbox не создавался. Рабочие боты, БД, роли пользователей и провайдеры не менялись. Нужна пересборка панели; новых миграций и изменений bot JARs нет.
