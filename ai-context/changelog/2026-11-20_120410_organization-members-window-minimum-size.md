# 01-301 — Размер окна состава оргструктуры

Промт пользователя:

> чуть лучше стало. но всё ещё маленькое окно. смотри на скрин

Приложен скриншот: широкое окно «Состав ветки IT-Dep» с очень малой высотой;
список сотрудников виден узкой полосой, верхние блоки ушли за прокрутку.

## Изменения

- Воспроизведён override новых стилей сохранённым размером 896 × 220 на viewport
  1280 × 663. Предыдущая проверка со свежим localStorage этого не покрывала.
- Для окна состава введены отдельные минимумы 900 × 640, ограниченные доступным
  экраном. Resize runtime применяет их при восстановлении, keyboard/pointer resize
  и изменении viewport. Общие минимумы других окон остаются 320 × 220.
- По умолчанию ширина до 1120 px, высота — viewport минус 24 px. Меню выбора
  использует свободное место; header/footer остаются видимыми. В режиме выбора
  пояснение и preview уплотняются, на очень низком экране preview временно скрыт.
- CSS пересобран из SCSS. Cache versions settings.css и modal-resize.js обновлены
  до 20261120-org-window-r2. EmployeePicker, формы, данные и права не менялись.
- Browser regression дополнен прежним сохранённым размером, низкими viewport,
  проверкой минимальной высоты и отсутствия влияния на другое окно.
