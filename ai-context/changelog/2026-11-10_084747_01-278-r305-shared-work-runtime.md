## Результат

Реализован и активирован оставшийся lifecycle общих межбизнесовых задач,
проектов и Kanban. V88/V89 реально применены в рабочей БД; backend web/worker
обновлены через Compose --no-deps с сохранением по1 replica и конфигурации.
Боты, db-migrate и инфраструктура не пересоздавались; feature flags,
transport principals и настройки не менялись. Начальных shared grants,
участников, backfill и распределения старых владельцев нет.

- V89: shared_work_access_audit с before/after, numeric actor/target и raw
  actor snapshot; UPDATE/DELETE trigger. Аудит grants/member/owner/create
  атомарен с записью, переживает удаление account/root. Это не защита от
  владельца БД/TRUNCATE. History API/UI: OWNER/system admin для объекта,
  system admin для общего журнала,50 строк/string BIGINT cursor, stale guard.
- NotificationRoutingService разворачивает аудиторию до READ-фильтра.
  NotificationService/Repository замораживают kind/object/numeric recipient;
  текущий READ действует до записи, list/count/pagination/read mutation и
  фактического SSE. Account/role/module/member revoke и username reuse
  не открывают старое уведомление. Публичный payload только reason/emittedAt.
  Legacy unowned task/project notices не обходят фильтр.
- PanelTaskService/TaskDomainFoundationService/DialogAutoCloseFollowUpTaskService:
  отдельный trusted producer с numeric eligible owner, canonical source ticket
  READ и project READ/WRITE. Root/OWNER/sequence/link/system audit атомарны,
  SecurityContext не подменяется; unsafe GENERAL/unresolved legacy fallback
  пропускается. Старые unauthenticated create overloads закрыты.
- ManagerReportService, DialogClientContextReadService,
  IncidentRelatedObjectService применяют текущую task видимость до counts/LIMIT.
  IncidentService использует scoped picker; TaskApiController скрывает
  incident summaries от обычных task участников до отдельной incident policy.
- Реальный вход выявил прежнюю ошибку создания пользователя: PostgreSQL
  registration_date получал varchar. AuthManagementApiController теперь связывает
  OffsetDateTime; добавлены2 реальные PG/MVC проверки. Только этот controller
  bytecode отличается между core и финальным web artifact.
- README, task01-278, S0, BOT_RUNTIME_CONTRACT и shared-work-access runbook
  обновлены по фактическому рабочему состоянию и оставшимся блокам.
