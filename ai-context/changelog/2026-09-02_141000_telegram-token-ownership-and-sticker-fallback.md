# Telegram token ownership and sticker fallback

## Пользовательский запрос

`так исправь чтобы всё работало`

## Фактические изменения

- Каналы без `credential_id` теперь используют собственный сохранённый token, а не первый credential той же платформы.
- Устранена внутренняя причина Telegram `409 Conflict`, дублей и пропусков updates при нескольких Telegram-каналах.
- При ошибке отображения TGS панель предлагает открыть или скачать исходный стикер.
