# 2026-11-27 — единое оформление прав сотрудника и роли [01-329]

## Изменения

- Общий компонент редакторов прав: поиск, сворачиваемые разделы, счётчики,
  согласованные отступы/цвета/типографика, адаптация к телефону и низкому окну.
- В правах сотрудника явно разделены роль, индивидуальное исключение и итог.
  Ошибка сохранения оставляет черновик; повторный клик и устаревший ответ защищены.
- Правки стилей сосредоточены в одном SCSS partial и общем CSS entrypoint,
  подключённом на /settings и /users. Старые определения ролей из трёх partials
  удалены. Убран конфликт с generic collapse CSS (двойная стрелка) и исправлен
  контраст close button в тёмной теме Bootstrap 5.3.0.
- Серверная логика прав, API и БД не изменены. Сохранены capabilities/admin locks,
  wildcard, legacy page grants и права скрытых поиском строк.
